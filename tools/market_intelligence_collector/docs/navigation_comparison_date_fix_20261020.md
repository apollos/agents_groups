## 有界模型取证

`MIC_ACCEPTANCE_MODEL_IO=1` 仅在显式 `MIC_LOG_DIR` 位于仓库组件 `logs/` 且对应活动 run 日志时启用。默认关闭，不改变原请求诊断或输出。记录实际用户业务材料、选段、初筛预算及原响应，排除系统提示、配置和凭据，脱敏 URL 凭据等敏感值。
