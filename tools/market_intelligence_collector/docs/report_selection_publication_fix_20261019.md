**本轮实现**

1. 研究问题进入现有 SERP 批量初筛。`modeling/prompts.py`、`modeling/call_planner.py` 和新增 `task_triage.py` 将完整问题、固定的本轮参考时点、候选标题/摘要、URL、域名和原规则分交给同一次初筛。模型结合问题区分候选适配性、原文与转载、旧报告与较新报告、定期报告与预测，返回阅读排名及审核理由。代码不按公司、年份或关键词选择“最新”。标题和摘要只用于导航，不成为正式事实或披露日期证据。

2. 任务排名严格绑定本次比较的全部候选。重复、未知或遗漏 ID、非法布尔值、非有限或越界优先级、重复或不完整排名均拒绝整批排序，不应用部分有效条目、不追加模型重试。`task_triage_reviews` 保留原始响应与错误，来源元数据 `task_triage` 保存有效排名及 `compared_source_ids`。已发送但协议被拒绝的初筛仍计入实际调用次数。

3. 排名仅在同批候选间生效。先按既有规则分、目标/关联公司分区及第一手来源保留逻辑建立基准队列，再按模型排名交换同一有效批次原来占据的位置。未评估候选的位置保留；两批排名不合成为跨批语义比较。已在同批被模型排后的旧官网资料不会再次被第一手来源保留逻辑挪回前面。浏览器阅读 gate、原规则分和正式内容准入门槛继续生效。

4. 来源披露日期纳入统一内容审核。规范位于 `content_review_policy.py`，执行位于 `content_review.py`。模型在正常抽取响应中通过 `bindings["/source_publication"]` 绑定 observation claim，明确 `field_values.source_publication.date_role="source_publication"`、完整日期和连续正文引用。共享审核器检查引用、依赖、审核状态、日期格式及贡献间一致性；日期语义及归属仍由模型判断。报告期、业务发生日、批准日或签署日不自动成为公开披露日。既有解析器取得的明确发布元数据保留原始出处，冲突继续报告为冲突。

5. 未知日期材料可在原预算内使用正常抽取调用审核日期，但不能先进入正式结果。已有明确过期、未来或冲突日期的来源仍在模型前过滤；日期未知时，审核后重新执行原时间窗检查。缺失绑定、无效引用、未获支持、冲突、预算不足或模型无有效输出时，日期继续未知，近期正式内容不入库，保留阶段原因及覆盖缺口。披露日期成立也不等于“最新”成立；缺少截止时点的官方披露目录或相应证据时，最新性仍须列缺口。

6. PDF 输入保留有限的上下文。在现有字符数与选段数上限内，保留相关表格后，为已抽取范围的首段和末段留出连续正文上下文，供模型理解日期归属，不按日期关键词挑选或认定披露日。末段明确标注为“已抽取范围末段”，不能冒充完整文档最后一页；原 PDF 最多抽取 20 页的限制没有扩大。表格、单位、行名及数字仍按既有整体片段规则处理。

7. 日期证据随正式回读与缓存传递。来源元数据、报告 `source_publications`、来源解释与事件来源记录保留日期状态及证据。内容哈希相同不证明两个 URL 的公开发布日期相同：克隆时旧审核移入 `cached_source_publication`，明确绑定旧 `source_link_id`，当前来源使用本次日期证据；同一 canonical URL 的缓存复用保留旧来源引用，不声称重新核验。canonical 和内容哈希两条克隆路径在复制业务记录前重新检查取消/截止条件，防止停止后仍新增正式事实。

**预算、剩余限制与后续成功标准**

本轮没有扩大调用预算、放宽 90d 时间窗、降低 70 分入库门槛或更改已验收的 65536 模型输出上限；没有新增专门的日期判断或排名模型请求。日期审核复用当前来源的正常抽取响应，任务排序复用现有批量初筛；未知日期材料消耗的调用仍受原任务总上限约束。预算耗尽或证据不足时保留缺口，不能以重试凑出成功。

原验收文档授权的一次采集批次已经结束，不能继续消耗其“剩余预算”。后续真实复验须登记新批次并冻结版本、输入和截止时点，遵循原有环境、隔离、预算和收尾约束：每个 MIC 任务查询 2、成功读取 2、HTTP 尝试 2、浏览器尝试 2、模型与 Gateway 各 3、300 秒；整批 30 分钟；不自动重采、注入已知答案 URL 或覆盖原失败证据。

下一项业务工作是在上述有界复验中核查：Agent 是否优先取得符合完整问题的资料，并从正式出口交付截至新 T0 最新已披露定期报告的名称、报告期、披露日和官方最新性依据，以及同一报告期/口径的三指标本期与同期数据。近期事项仍须满足 90d 证据约束，并明确未覆盖方向。若只能取得某期准确财报、披露日仍未知，或没有证明“最新”的依据，财报部分继续判 INCONCLUSIVE，不能以接口成功或输出数量宣布通过。
