原响应同时生成了以下指标，并原样保留其错误比较值到存储、Agent读取及正式导出：

```json
{
  "metric_name": "营业收入同比增速",
  "metric_value": 147.42,
  "unit": "%",
  "period": "2026H1",
  "comparison": {"yoy": 1.4742}
}
```

来源t3明确是营业收入这一金额指标的本期/上年同期增减147.42%。
把它作为独立的“收入同比增速”指标是可行的，但再把同一数值挂进该指标的同比字段，
就错误暗示“增速自身同比增长147.42%”，来源没有支持这种二阶比较。
`rev_yoy_cmp` 的statement仍讲收入同比，绑定却是 `/metrics/0/comparison`，父指标已变成收入同比增速。
现有共享审核确认了引用、类型、比例换算与依赖，但不能因此证明比较对象与父指标的语义一致。
147.42 percent→1.4742 ratio的数值换算本身正确，问题是比较归属。

原响应的mom/wow空值在共享审核中被移除；错误的yoy在各阶段均保留。
可选身份、方向、影响渠道、uncertainty和问题列表仍存在缺失绑定，由共享审核隔离；本轮未宣称这些字段全部修复。
